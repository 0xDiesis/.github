# Diesis organization profile

[profile/README.md](profile/README.md) appears on the
[Diesis GitHub organization](https://github.com/0xDiesis).

The profile uses GitHub Markdown and HTML tables, with light and dark SVG
headers in [profile/assets](profile/assets). The headers use the Diesis Signal
palette and canonical wordmark. Keep essential descriptions and navigation in
the README so they remain readable without images.

Link to public repositories and follow each SDK’s guide for installation.
